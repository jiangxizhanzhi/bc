## JYJ项目开发
基于最新的5.3.1-develop分支开发

### 需求内容 模块 report_score
1. 竞赛打分系统
2. 态势展示系统

### 约定
1. 平台没有队伍模块，使用用户作为队伍名称
2. 排名展示，只显示指定的8个队伍，其它队伍排名默认为0
3. 平台同时启动4个结构相同的场景，4D态势只展示其中一个，4个场景拓扑结构都相同
4. 每个队伍固定IP，且不止一个

### 需要配置内容
修改 数据库表cr_report_score_config配置
- 配置参加比赛的8个用户 
- 配置态势展示头部名称
